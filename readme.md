# 背景 
日常工作场景中需要处理的电子文档大致可以分成两类 
1. 人工编写的文档, 最常见的是人工撰写的邮件
2. 基于程序或者模板(以下统称模板生成), 再填充动态的数据, 所生成的具有特定格式的文档. 例如大部分银行的信用卡账单, 由程序发出的固定格式邮件, 预定义的表单等等

这些文档中包含的信息, 通常需要人工阅读理解, 然后收集到下游程序或者数据集里, 很消耗人力并且可能出错. 所以存在对文档进行自动化信息提取的需求.

以下自动化信息提取方案只针对模板生成的文档, 对于人工编写文档的信息提取则不在考虑范围

# 解决思路
对于任何待处理文档, 先判断是否属于模板生成, 如果是, 则用预定义的信息提取规则进行信息提取和校验, 最后输出结构化的信息.
